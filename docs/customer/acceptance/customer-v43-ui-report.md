# 客服界面与会话管理验收

日期：2026-10-03；环境：本地 OrangeJD，前端 15173，后端 18080。

## 实现

- 平台导航沿用原布局和颜色，增加项目客服入口；移除菜单固定高度和矮屏压缩规则，菜单由已有滚动区域承载。
- 聊天内容和输入区取消居中窄栏：用户右侧浅橙气泡、AI 左侧白色气泡、暖灰背景。条件、来源、推荐卡片和处理进度保留。
- 移除模型名称、思考模式、Token 和费用展示；后台计量保留。
- 会话支持确认后删除，当前会话删除后清空显示与条件；生成中先停止。删除失败保留原会话。
- V42 会话删除迁移已在现有本地数据库由 Flyway 应用。服务端执行归属和白名单检查，并通过共享事务锁排除提交与删除竞态。软删除保留费用审计记录，客服接口不再暴露已删除历史与运行。

## 使用

访问 `http://127.0.0.1:15173/customer`，左侧会话条目右边的垃圾桶按钮用于删除。生成中的会话先点击“停止”，等待进入终态再删除。

## 发布与回退

正式发布需先应用 V42，再部署后端和前端。功能关闭仍使用原客服开关；A 版入口保持原状。
若回退客户端/服务端版本，应保留 V42 数据库列。旧版本未过滤 `deleted_at`，可能重新显示已删除会话，不能直接作为删除功能的回退版本；应保留删除过滤补丁，或关闭客服直至修复。
