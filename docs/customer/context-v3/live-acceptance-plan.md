建议本轮新增最多 40 次真实出站尝试，包含理解、检索规划、用途/证据/需求核验、建议、摘要、Embedding 和失败重试。以 HTTP 边界账本为准，达到上限停止；不以聊天轮数代替请求数，不宣称所有场景一定能在该额度内完成。

优先级为短对话 → 长历史/摘要 → 任务恢复/歧义 → 推荐/严格/库存。每个运行串行执行。余量低于完成一轮推荐所需预算时停止启动复杂请求，记录未执行项，不回收失败次数。

逐轮保存输入、run/session/task 身份、业务状态、需求快照、来源/摘要引用、实际模型阶段和尝试次数、耗时、错误。人工审阅语义结果；HTTP SUCCEEDED 本身不代表通过。短对话耗时和推荐耗时分别报告，不以小样本宣称稳定 P95。
