## 已修复但等待真实复测

- 首次引用失败涉及模型复制原文时改变引文，以及解释缺乏支持。现在服务端生成子片段编号，模型选择编号，服务端恢复原文，再核对事实支持；不支持的解释删除，全部不支持时拒答。本地校验通过，真实收益未证实。
- 平台把 `Long` 序列化成字符串。已修复历史候选指代、方案草稿校验、证据版本 ID 和同步任务 ID 的读取；回归覆盖字符串 ID、越界与非法数值，以及“第二个项目”恢复。此前失败的同步任务没有自动重放，需审核后重试并验收。
- 修改条件必须提供对应原话，取消 Docker 不能顺带取消语言；改变学习／求职目标会失效旧候选列表。
- A 的偏好排序回归暴露既有加权问题，已修复为相对 RRF 分数的加权。后续 A/B 对比必须冻结新的 A 代码基线，不能直接沿用旧 A 结果。
