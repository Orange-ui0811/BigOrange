# 客服 v4.5–v4.11 修复记录

本次修复依据 2026-10-03 的八画像双链路测试，不更换 B 索引或模型厂商。

## 已实现

- 主题统一为最多六项短字符串列表，兼容已有单字符串会话；模型工具 Schema 明确各字段类型。多主题格式错误先走模型适配层的一次受限修复，不直接伪装成用户语义不清。
- 条件拒绝日志保留字段、原因、值类型，不写出真实画像原文。单独“确认”只执行已保存操作；保留明确取消语句的旧会话兼容路径。
- 新增严格核实/允许相关探索两种模式；本轮明确“只推荐可核实符合条件”优先于通用的探索许可。保留硬件限制，未知硬件要求不通过严格模式。
- 未匹配主题的抓取仓库不能通过“未知字段”绕过主题限制。明确的资源清单不作为可做作品推荐；已确认条件和可用知识文档优先，再使用现有相关性及偏好排序。
- 外部仓库可用当前文档标题及前 12000 字符做本地主题筛选，文本不进入卡片响应。不从正文关键词猜测主语言、周期或资源布尔值。长文后部主题仍可能漏召回，需要后续结构化元数据任务解决。
- v4.9保留聊天/条件理解的思考模式，证据摘取和事实核验单独采用普通模式；最终预算为4096、2048、2048。v4.5–4.8尝试增加全阶段思考预算到8192后，仍有截断与核验超时，故不继续无限加大预算。单次最多45秒、整轮最多90秒不变；预算上限不是实际费用。截断允许一次增大预算重试，最高8192，受剩余期限限制。
- 模型记录增加阶段、请求模型、实际返回模型、finish_reason、输出预算、错误码；用量仍包括失败和重试。
- 证据生成采用最多六条、每项目最多两条的指令，按功能、前置条件、风险、实践入口等字段生成；兼容旧格式的服务端校验仍最多九条。仅通过原文定位和事实核验的内容可以填入卡片；没有引用或者条件待核实时，不标为 VERIFIED_PROJECTS，不允许导入方案。
- 项目身份允许同一项目的学习与职业资料互相补充证据，并兼容仓库名大小写；不同项目不能串用引用。
- 有待确认条件时，普通问答和诊断仍可继续，不被推荐前的确认分支一并阻断。
- v4.6 将实践方向、可选使用场景保存为有原话依据的 preferences，随会话恢复；不能把必须、禁止等明确限制放入偏好绕过校验。确有歧义的硬条件仍需澄清。
- v4.6 证据查询由功能、部署和用户问题构成，不再拼接所有仓库名触发名称加分；项目身份仍由文档集合约束。限定范围内取 20 个片段，再过滤纯标题、图片徽章、链接目录并按项目分配证据预算。过滤仅用于选择，引用保留未改动的原文和定位。
- v4.7 预算估算与真实发送使用相同的完整问题（包含历史实践偏好），修复 v4.6 临发送时追加字段导致超预算的问题。片段开头的长徽章段不再挤掉正文，引用窗口记录相应原文偏移。新增预算与原文窗口定位回归。
- v4.8 修正片段窗口：只跳过开头的装饰，不因行短而删去 Java 版本、命令、表格等事实。核验提供受控来源身份以解析主语，但身份不得当作功能事实依据。记录每条待核验陈述、原文和结论。证据模型只解释已选候选的已知事实，不重复筛选或因周期未知丢弃功能说明。
- v4.9 已确认的单一语言限制若被模型重复放入偏好，不再制造第二个澄清项；不同语言仍不能被当作已处理。原始引用校验、事实核验、未知条件禁止导入均保留。
- v4.10 原话允许纯空白差异，并还原保存真正的连续原文；不同文字、数字、否定词不会被模糊匹配放过。仓库开头明确自述“A concurrent Go CLI”等限定语法时，记录带原文依据的语言字段，已知与Java冲突的候选不再按未知放行；不是扫描全文任意语言关键词。教程/指南 compilation 类集合不作为作品推荐。
- v4.11 多仓库生态链接列表不能填入当前项目的 description 字段，避免把 vue-echarts 等关联组件当作 Apache ECharts 自身介绍；保留代码中的可复现反例测试。

## v4.13–v4.15：自由主题用途核对与真实复测（2026-10-04）

最终本地运行版本为 `customer-v4.15-purpose-review`。A与原智能分析未改动；B继续使用 `20261002164953-ec113424` 代际、bge-m3结构分块混合索引，无数据库迁移或重建。

实现：

1. 用户原主题及原话独立保留。QUERY_PLAN生成最多3个中英文完整用途短语，只用于检索，不写回用户条件；不再把英文短语拆成data/and等泛词进行命中加分。
2. B召回与业务用途说明共同提名，去重后最多12个候选。README去徽章、图片与链接展示噪声后再裁剪；用途判断继续服从6000字符保守输入预算。
3. PURPOSE_REVIEW核对主要功能/合理子任务，读取原话的使用对象；依赖关键词、文档框架和任意文件操作不再自动等于主题匹配。只接受给定ID、合法关系及输入中的连续引文。
4. 接受结论绑定主题、原话、项目身份和资料摘要哈希；详情、推荐最终校验与导入重读资料，变化后旧结论失效。语言/周期/资源/下架条件仍独立执行；未知值不能称为满足条件。
5. 无结果试算保留主题，仅计算其他条件变化；移除固定跨领域主题列表，不自动套用建议，不显示候选计数。没有可靠方案时明确说明并继续询问目标中的具体功能。
