# 同画像 B 双产品对照口径

用户授权：8 个合成画像、两轮、16 次智能分析与 16 次客服，最多 112 次底层模型调用，允许证据发送至 Gitee Pro 和 DeepSeek Flash。测试不扣平台积分，不读取真实画像或已有历史。

两侧使用相同需求。智能分析接收结构化画像并在自定义需求中附带完整话术；客服接收完整话术，必须自行提取条件。后者的理解失败属于产品结果，不能预先注入提取结果掩盖。测试账户现有有效画像为空，每个客服请求新建会话。顺序固定种子随机化，同一案例两侧相邻执行，单并发。

产品使用现有不同模型、提示词、候选池与约束策略，结论限定于当前配置的真实产品链路，不作为模型或 RAG 单因素因果实验。智能分析采用开发实验接口调用实际分析器，不覆盖前端、积分扣减及历史保存；客服通过真实会话运行接口，未做浏览器截图验收。

分开统计：运行终态、是否给出卡片、是否需要澄清、卡片内容与项目适合程度、条件提取、引用与可导入状态、时延、全部模型尝试及用量。成功但需澄清、无结果、证据生成失败后降级，不能计为推荐完成。

卡片字段按共享前端组件的可见字段检查：描述、实践参考、推荐理由、前置条件、已有分析、改造方向、能力证明、风险、本轮证据。统计覆盖与字符量只衡量内容量，不能直接等同正确率；通用占位说明不等同具体环境依赖。分析的全局趋势、学习步骤不计入单张卡片。

核查真实项目标识和链接，明确条件不应被静默放宽。待核实探索候选不视为满足条件。引用存在性与事实支持分开审阅，已有数据库分析不视为本轮证据核验。两轮项目集合按规范化 URL 比较；两轮均空的结果不计为非空推荐稳定。

费用按供应商公布单价与真实用量估算，并包含失败与重试；不是供应商账单。完成 Token 已包含思考 Token，不重复计费。缺失用量保留未知；Embedding 用量未返回，不编造金额。Flash 按本轮周末空闲价：每百万缓存命中输入 0.02 元、未命中输入 1 元、输出 4 元。Gitee 请求 SKU DeepSeek-V4-Pro 按每百万输入 12 元、输出 24 元。不得使用官方 Pro 单价替代 Gitee 单价。

原始记录、提示词快照、步骤、版本、索引前后快照保留。完成后仅软删除本次新会话；不改模型配置、不修代码、不重建索引，避免把两个不同版本混在同一实验。
