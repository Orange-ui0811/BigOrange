# V4.1 Flash 思考模式对照（2026-10-03）

客服已使用独立 `CUSTOMER_MODEL=deepseek-flash`。DeepSeek 官方当前将该名称指向 V4.1 Flash；现有文本模块继续使用 `deepseek-v4-pro`，客服检索的 bge-m3 未改动。本地容器重建成功，应用未登录接口返回 401，符合鉴权预期。默认 `CUSTOMER_THINKING=false`，可用环境配置开启；本轮没有部署生产。

官方模型与价格依据：https://api-docs.deepseek.com/quick_start/pricing/

## 实验设计

8 个合成场景：条件修改、条件隔离、列表指代、严格筛选、英文证据中文提问、证据不足、版本冲突、资源预算。每个场景每种模式重复两次，共 32 次调用。只发送合成对话和模拟资料，无平台文档、真实画像和历史。使用同一系统提示、temperature=0、JSON 输出，思考开启为 high，单次超时 45 秒、输出上限 1500 Token。两种模式每题并行，第二轮交换提交顺序，记录实际缓存用量。

这是 8 个独立场景，重复两轮不是 16 个独立场景。不是完整客服工具链、全库检索、RAGAS 或上线验收；仅比较模型在当前客服输出预算下的表现。未测试 low/max 思考强度。

## 主实验结果

| 指标 | 关闭思考 | 开启思考（high） |
|---|---:|---:|
| 请求数 | 16 | 16 |
| 业务事实正确 | 14/16（87.5%） | 14/16（87.5%） |
| 原始严格字段匹配 | 12/16 | 14/16 |
| 有效 JSON | 16/16 | 14/16 |
| HTTP／传输错误 | 0 | 0 |
| 输出预算耗尽 | 0 | 2 |
| 平均耗时 | 611 ms | 2053 ms |
| P95 | 864 ms | 8822 ms |
| 总 Token | 3424 | 8826 |
| 输出 Token（包含思考） | 260 | 5262 |
| 返回的思考 Token | 0 | 5015 |
| 本组估算费用（USD） | 0.000592968 | 0.003616536 |

端口题未指定 JSON 字段类型，关闭模式两次把 8181 返回为字符串，事实仍正确。因此原始严格匹配记录保留，业务评分仅对此项接受等价数字字符串；没有重新调用或修改原题。不能把这个差异当成检索或事实失败。

关闭模式的两次业务失败均为资源题：推荐了 Docker 需求未知的项目。开启模式在同题两次耗尽输出预算，仅返回思考，没有最终答案。开启模式平均约慢 3.36 倍，输出 Token 约为 20.24 倍，本组估算费用约为 6.10 倍；这些比例只适用于这组题。

费用按官方 2026-10-03 周末非高峰价计算：缓存命中输入 $0.003/百万 Token，未命中输入 $0.15/百万，输出 $0.6/百万，使用实际返回的 cache-hit/cache-miss 和 completion 用量。金额是用量乘公开单价的估算，不是账户账单；未换算人民币。缓存比例不相同已按实际分别计算，不能把费用差全部解释为思考 Token。

## 配置建议与边界

当前保持关闭思考，原因是这组题未提高业务正确率，却显著增加延迟与费用，且存在耗尽预算没有最终答案的情况。这不代表思考模式在复杂任务中没有价值。未来如要用于复杂比较，需单独测试更明确的 Prompt、较低思考强度和专用预算，并证明质量收益后再启用。

语言、发布状态、资源限制、未知值和方案导入资格继续由 Java 校验；不能把模型的项目选择直接写入正式方案。本轮资源题失败说明这层校验必要。

代码回归 `flash-config-tests.log` 通过，架构检查通过。真实客服生成质量、引用、成本及独立验收仍待完成，不能沿用此前 Pro 版结果宣称 Flash 通过。先前针对内部资料外发的审批仍未解决；本轮合成实验不替代该授权。
