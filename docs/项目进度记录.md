| `category` | ✅ 已建 | Phase 2 启用 |

### API 端点（6 个）

| 方法 | 路径 | 鉴权 | 用途 |
|------|------|------|------|
| POST | `/admin/auth/login` | 无 | 管理员登录 |
| PUT | `/admin/auth/password` | Admin JWT | 管理员改密 |
| POST | `/app/auth/login` | 无 | 用户登录 |
| POST | `/app/auth/register` | 无 | 用户注册 |
| PUT | `/app/auth/password` | App JWT | 用户改密 |
| GET | `/app/auth/logout` | App JWT | 退出 |

### 关键设计

- **双通道 JWT**：admin 和 app 两套密钥，token 互不通用
- **BCrypt 密码**：不存明文，每次登录做哈希比对
- **注册即登录**：注册成功直接返回 JWT，无需二次登录

### 新增 API（22 个）

| 模块 | 端点 |
|------|------|
| 作品 | `POST/PUT/DELETE/GET /app/work`、`GET /app/work/my`、`GET /app/work/public`、`POST /app/work/{id}/submit`、`PUT /app/work/{id}/visibility` |
| 需求 | `POST/PUT/DELETE/GET /app/requirement`、`GET /app/requirement/my`、`GET /app/requirement/public`、`POST /app/requirement/{id}/submit`、`PUT /app/requirement/{id}/visibility` |
| 审核 | `GET /admin/audit/works`、`POST /admin/audit/work/{id}/approve`、`POST /admin/audit/work/{id}/reject` |
| | `GET /admin/audit/requirements`、`POST /admin/audit/requirement/{id}/approve`、`POST /admin/audit/requirement/{id}/reject` |
| 管理端扩展 | `GET /admin/work`、`GET /admin/work/{id}`、`PUT /admin/work/{id}/offline` |
| | `GET /admin/requirement/{id}`、`PUT /admin/requirement/{id}/offline` |

### 关键设计

- **审核状态机**：`DRAFT → PENDING_REVIEW → APPROVED / REJECTED`，拒绝后可重新提交
- **编辑退回**：APPROVED 作品被编辑后自动退回 DRAFT，需重新审核
- **下架 = REJECTED**：管理端下架将状态设为 REJECTED + PRIVATE，写入审核记录
- **删除不限状态**：任何状态均可删除，仅本人可操作
- **隐私切换**：随时可切换 PUBLIC/PRIVATE

## Phase 5 完成详情（2026-06-09）

### 新增表（3 张）

`conversation` / `message` / `notification`

### 新增 API（10 个）

| 模块 | 端点 | 用途 |
|------|------|------|
| Conversation | `POST /app/conversation` | 发起会话 |
| | `GET /app/conversation/list` | 会话列表（含未读数+最新消息） |
| | `GET /app/conversation/{id}` | 会话详情 |
| | `DELETE /app/conversation/{id}` | 删除会话+全部消息 |
| Message | `POST /app/message` | 发送消息 |
| | `GET /app/message/{convId}` | 消息历史 |
| | `PUT /app/message/{convId}/read` | 标记已读 |
| Notification | `GET /app/notification/list` | 通知列表 |
| | `PUT /app/notification/{id}/read` | 标记已读 |
| | `GET /app/notification/unread-count` | 未读数 |

### 通知触发点（6 个事件）

- 审核通过/拒绝 → `AUDIT` 通知作者
- 收到新消息 → `MESSAGE` 通知接收方
- 收藏 → `FAVORITE` 通知内容作者
- 评论 → `COMMENT` 通知内容作者
- 报价单状态变更 → `QUOTE` 通知双方
- 管理员下架 → `AUDIT` 通知作者

### 业务规则

- 不能向自己发起会话
- 同一作品/需求同两人不重复建会话
- 非参与方不能查看/发送消息
- 通知只能本人标记已读

### 新增 API（15 个）

| 模块 | 端点 | 用途 |
|------|------|------|
| Quote | `POST /app/quote` | 从会话发起报价 |
| | `PUT /app/quote/{id}/accept` | 接受报价 |
| | `PUT /app/quote/{id}/reject` | 拒绝报价 |
| | `PUT /app/quote/{id}/cancel` | 取消报价 |
| | `GET /app/quote/{id}` | 详情 |
| Order | `POST /app/order` | 创建订单（来自报价/直接购买） |
| | `GET /app/order/{id}` | 详情（含支付阶段+交付记录） |
| | `GET /app/order/buy` | 买入列表 |
| | `GET /app/order/sell` | 卖出列表 |
| | `PUT /app/order/{id}/deposit` | 付定金 |
| | `PUT /app/order/{id}/deliver` | 交付 |
| | `PUT /app/order/{id}/final-pay` | 付尾款 |
| | `PUT /app/order/{id}/cancel` | 取消 |
| | `DELETE /app/order/{id}` | 删除（仅 COMPLETED/CANCELLED） |

### 订单状态机

```
CREATED → WAITING_DEPOSIT → DEPOSIT_PAID → IN_PROGRESS
  → WAITING_FINAL_PAYMENT → DELIVERED → FINAL_PAID → COMPLETED
  ↓ 任何阶段
  CANCELLED / DISPUTED
```

### 两条交易路径

- **路径 A（协商）**：聊天 → 报价 → 接受 → 自动生成订单
- **路径 B（直接购买）**：作品详情 → 直接下单

### 通知事件（双方通知）

- 创建订单 → 「订单已创建」「你有一个新订单」
- 付定金 → 「定金支付成功」「买家已支付定金」
- 交付 → 「卖家已提交交付」「交付已提交」
- 付尾款 → 「尾款支付成功，订单完成」「买家已支付尾款」
- 取消 → 通知对方

### 定时任务

- `QuoteTimeoutTask`：每 10 分钟扫描过期报价自动设为 EXPIRED
- `OrderTimeoutTask`：骨架，后续完善

## 使用说明

### 环境要求

| 组件 | 版本 | 说明 |
|------|------|------|
| Java | 21 | 本地 JDK |
| MySQL | 8.0 | 端口 3306，root / 123456 |
| Maven | 3.x | 项目构建 |
| 浏览器 | 任意 | 打开 `test-frontend.html` 即可调试 API |

### 启动应用

```bash
cd D:\Orangejd
mvn install -DskipTests -q    # 首次或新增了 pojo 类时需要
mvn spring-boot:run -pl orange-server
```

如遇端口占用：
```bash
powershell -Command "Stop-Process (Get-NetTCPConnection -LocalPort 8080 -ErrorAction SilentlyContinue).OwningProcess -Force"
```

### 前端调试面板

浏览器直接打开 `D:\Orangejd\test-frontend.html`

### 查看数据库

**MySQL Workbench**：打开 `D:\MYSQL\MySQLWorkbench.exe` → 新建连接：
- Host: `127.0.0.1`，Port: `3306`，User: `root`，Password: `123456`
