## 2026-06-07

### Phase 0 — 骨架确认 + 基线评估

- 项目结构：`orange-server` / `orange-pojo` / `orange-common` / `orange-admin` / `orange-web`
- 技术选型：Spring Boot 2.7 + MyBatis-Plus + MySQL + Vue 3 + Element Plus
- 数据库全量设计 `schema-v1.sql`

### Phase 1 — 账号体系

#### 数据库表

| 表名 | 说明 |
|------|------|
| `account` | 账号，含初始 admin（密码 123456） |
| `user_profile` | 用户资料，与 account 一对一 |

#### API（6 个）

| 方法 | 路径 | 鉴权 | 用途 |
|------|------|------|------|
| POST | `/admin/auth/login` | 无 | 管理员登录 |
| PUT | `/admin/auth/password` | Admin JWT | 管理员改密 |
| POST | `/app/auth/login` | 无 | 用户登录 |
| POST | `/app/auth/register` | 无 | 用户注册 |
| PUT | `/app/auth/password` | App JWT | 用户改密 |
| GET | `/app/auth/logout` | App JWT | 退出 |

#### 关键设计
- 双通道 JWT：admin/app 两套密钥，token 互不通用
- BCrypt 密码不存明文
- 注册即登录，直接返回 JWT

### Phase 3 — 内容发布（作品/需求/审核）

#### 新增表（4 张）
`work` / `work_sale_option` / `requirement` / `audit_record`

#### 新增 API（22 个）

| 模块 | 端点 |
|------|------|
| 作品 | `POST/PUT/DELETE/GET /app/work`、`GET /app/work/my`、`GET /app/work/public`、`POST /app/work/{id}/submit`、`PUT /app/work/{id}/visibility` |
| 需求 | `POST/PUT/DELETE/GET /app/requirement`、`GET /app/requirement/my`、`GET /app/requirement/public`、`POST /app/requirement/{id}/submit`、`PUT /app/requirement/{id}/visibility` |
| 审核 | `GET /admin/audit/works`、`POST /admin/audit/work/{id}/approve`、`POST /admin/audit/work/{id}/reject` |
| 管理端 | `GET /admin/work`、`GET /admin/work/{id}`、`PUT /admin/work/{id}/offline`、`GET /admin/requirement/{id}`、`PUT /admin/requirement/{id}/offline` |

#### 关键设计
- 审核状态机：`DRAFT → PENDING_REVIEW → APPROVED / REJECTED`
- 编辑退回：APPROVED 作品编辑后自动退 DRAFT
- 下架 = REJECTED + PRIVATE + 审核记录
- 删除不限状态，仅本人可操作

### Phase 4 — 内容发现（市场/收藏/评论）

#### 新增表（3 张）
`favorite` / `comment` / `browse_history`

#### 新增 API（15 个）

| 评论 | `POST/DELETE /app/comment`、`GET /app/comment/{type}/{id}`、`GET /app/comment/my`、`GET /app/comment/on-my-content` |

| 主页 | `GET /app/profile/{accountId}`（隐私过滤） |

#### 关键设计
- 评论删除权限：管理员 > 内容主人 > 评论作者
- 作者主页隐私：非本人只展示 `APPROVED + PUBLIC`

### Phase 6 — 交易闭环（报价/订单/支付）

#### 新增表（4 张）
`quote` / `order` / `payment_stage` / `delivery`

#### 状态常量
`QuoteStatus`（5 状态）/ `OrderStatus`（10 状态）/ `PayStatus`（UNPAID/PAID）

#### 新增 API（15 个）

| 模块 | 端点 | 用途 |
|------|------|------|
| Quote | `POST /app/quote`、`PUT accept/reject/cancel`、`GET` | 报价 CRUD |
| Order | `POST /app/order`、`GET /{id}`、`GET buy/sell` | 订单 CRUD |
| | `PUT deposit/deliver/final-pay/cancel`、`DELETE` | 状态流转 |

#### 订单状态机
```
CREATED → WAITING_DEPOSIT → DEPOSIT_PAID → IN_PROGRESS
  → WAITING_FINAL_PAYMENT → DELIVERED → FINAL_PAID → COMPLETED
  ↓ 任何阶段 → CANCELLED / DISPUTED
```

#### 交易路径
- 路径 A（协商）：聊天 → 报价 → 接受 → 订单
- 路径 B（直接购买）：作品详情 → 下单

## 2026-06-16

### 上线准备 S3 — 部署上线完成

#### 部署问题修复

| 问题 | 现象 | 修复 |
|------|------|------|
| Nginx `try_files` 在 server 层劫持 POST | 登录 502 | 移至 `location /` 内 |
| Admin `location /admin` 无 `^~` | JS/CSS 被正则截胡 → 404 | `location ^~ /admin` |
| `request.js` 拦截器返回 body → 组件取值错 | 登录无反应 | `res.data.code` → `res.code` |
| Admin `vite.config.js` 缺 `base` | HTML 引用 `/assets/` → 404 | `base: '/admin/'` |

#### 部署命令

```bash
cat > /root/start.sh << 'EOF'
#!/bin/bash
export PATH=$PATH:/www/server/java/jdk-17.0.8/bin
export MYSQL_USER=root
export MYSQL_PASSWORD='Az919800.'
export MYSQL_DB=orangejd
export REDIS_PASSWORD='Az919800.'
export UPLOAD_PATH=/root/uploads
java -jar /root/orange-server-1.0.0-SNAPSHOT.jar --spring.profiles.active=prod
EOF
chmod +x /root/start.sh
pkill -9 -f orange-server
sleep 2
nohup /root/start.sh > /root/app.log 2>&1 &
sleep 25
curl http://127.0.0.1:8080/health
```
