### 解决的问题

| 问题 | 解决 |
|------|------|
| 无 SSH 密钥 | 生成 ed25519，配 GitHub |
| Git remote 分叉 | `pull --allow-unrelated-histories` 合并 |
| 无数据源配置 | 添加 spring.datasource 到 application-dev.yml |
| @ComponentScan 范围不足 | 扩展至 common/pojo/server 三模块 |
| Controller 类名冲突 | 重命名为 AdminAuthController / AppAuthController |

| Java 21 缺 JAXB | 添加 jaxb-api 依赖 |
| JWT 异常返回 500 | 拦截器 try-catch 返回 401 |

## 使用说明

### 环境要求

| 组件 | 版本 | 说明 |
|------|------|------|
| Java | 21 | 本地 JDK |
| MySQL | 8.0 | 端口 3306，root / 123456 |
| Maven | 3.x | 项目构建 |
| Redis | 未安装 | 当前可不用，后续启用 |

### 启动应用

```bash
cd D:\Orangejd
mvn spring-boot:run -pl orange-server
```

看到 `Started OrangeApplication in X seconds` 即启动成功，监听 `http://localhost:8080`。

如遇端口占用，杀掉旧进程：
```bash
powershell -Command "Stop-Process (Get-NetTCPConnection -LocalPort 8080 -ErrorAction SilentlyContinue).OwningProcess -Force"
```

### 测试 API（Git Bash / Linux 终端）

```bash
# 管理员登录
curl http://localhost:8080/admin/auth/login -X POST \
  -H "Content-Type: application/json" \
  -d '{"username":"admin","password":"123456"}'

# 用户注册
curl http://localhost:8080/app/auth/register -X POST \
  -H "Content-Type: application/json" \
  -d '{"username":"test1","password":"123456","nickname":"测试"}'

# 用户登录
curl http://localhost:8080/app/auth/login -X POST \
  -H "Content-Type: application/json" \
  -d '{"username":"test1","password":"123456"}'

# 改密码（需替换 TOKEN）
curl http://localhost:8080/app/auth/password -X PUT \
  -H "Content-Type: application/json" \
  -H "App-Token: <你的token>" \
  -d '{"oldPassword":"123456","newPassword":"654321"}'
```

### 测试 API（PowerShell）

```powershell
$body = '{"username":"admin","password":"123456"}'
Invoke-RestMethod -Uri http://localhost:8080/admin/auth/login -Method Post -Body $body -ContentType "application/json"
```

### 查看数据库

**MySQL Workbench**：打开 `D:\MYSQL\MySQLWorkbench.exe` → 新建连接：
- Host: `127.0.0.1`，Port: `3306`，User: `root`，Password: `123456`

**命令行**：
```bash
mysql -u root -p123456 orangejd -e "SELECT * FROM account;"
mysql -u root -p123456 orangejd -e "SHOW TABLES;"
mysql -u root -p123456 orangejd -e "DESC account;"
```
