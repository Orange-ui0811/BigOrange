# ADR 0002：使用持久化后台任务

- 状态：Accepted
- 日期：2026-07-25

## 背景

榜单、Issue、AI 审核和翻译曾使用裸线程、公共异步线程池或进程内重试。应用重启会丢失状态，无限重试会占住工作线程，多实例会重复执行。

## 决策

使用 MySQL `system_task` 作为当前规模下的持久化任务中心。任务通过业务幂等键入队，数据库原子抢占，失败进入 `RETRY_WAIT`，过期锁可恢复。执行线程由 Spring 管理。

## 结果

任务可恢复、可审计并支持未来多实例。当前不引入额外消息队列；只有吞吐或隔离需求超过数据库队列能力时再评估迁移。
