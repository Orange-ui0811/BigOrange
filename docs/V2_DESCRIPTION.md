# BigOrange V2 版本说明

## 对比基线

- GitHub 分支：`origin/main`
- 对比提交：`603f841`
- V2 定位：在不改变 Java / Vue / MySQL / Redis 主体架构的前提下，将项目从功能原型完善为具备本地完整运行、内容审核、视频作品展示、交易接入和上线安全基线的版本。

## 核心变化

### 1. 作品发布与内容体验

- 作品发布支持直接上传 MP4、MOV、M4V、WebM 视频文件，不再要求用户填写视频链接。
- 上传过程提供格式、MIME、文件头和 200MB 大小校验，并展示上传进度、预览、替换和移除操作。
- 用户端作品详情自动加载站内视频播放器；作品市场增加视频标识。
- 管理端待审详情、作品管理详情和独立详情页自动显示视频播放器，管理员无需打开外部链接即可审核。
- 调整用户端与管理端导航、页面布局、移动端适配、操作反馈和可访问性细节。

### 2. 账号与访问安全

- 强化登录、注册、密码修改和密码重置参数校验。
- 完善 JWT 角色隔离、令牌黑名单、WebSocket 临时票据和管理员接口权限控制。
- 增加登录、验证码、AI 调用及关键接口的限流保护。
- 增加内容所有权校验，限制未审核或非公开内容的越权读取。
- 加强 URL 安全校验、分页边界控制、跨域配置、请求追踪和敏感日志治理。
- 生产环境启动时校验 JWT、数据库、Redis、邮件、支付等关键配置，阻止弱配置直接上线。

### 3. 支付与交易安全

- 接入 Epay 聚合支付，可承载支付宝和微信支付渠道。
- 补充支付配置校验、签名验证、金额复核、回调幂等和支付事件审计。
- 将支付业务处理与回调入口解耦，避免重复通知导致重复入账。
- 生产环境默认关闭模拟支付，降低错误配置引发的交易风险。

### 4. 数据与文件治理

- 引入 Flyway 增量迁移并补齐运行所需表结构，新增支付回调事件和作品视频字段。
- 上传文件使用受控目录、随机文件名和内容特征校验，阻止目录穿越与伪造文件类型。
- 完善数据库备份脚本、保留策略和恢复前检查说明。
- 本地验证码仅在 `dev` 环境输出，生产环境继续使用 SMTP 邮件服务。

### 5. 部署与运维

- 新增 Docker Compose 本地环境，一次启动 MySQL、Redis、后端、用户端和管理端。
- 提供本地及生产环境变量模板，避免真实密钥进入版本库。
- 完善 Nginx HTTPS、安全响应头、CSP、限流、上传大小和静态资源缓存配置。
- 增加健康检查、结构化日志和生产上线安全与数据治理文档。
- 更新 README 与商业计划书，使产品说明和当前实现保持一致。

## 兼容性说明

- 主体技术架构与既有数据库模型保持兼容，通过增量迁移升级。
- 原有图片、作品、需求、聊天、收藏、评论、AI 工具和后台管理流程继续保留。
- 旧作品中的外部视频地址可继续只读展示；再次编辑时需要重新上传站内视频文件。
