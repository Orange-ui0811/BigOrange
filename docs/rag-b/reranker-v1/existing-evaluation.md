# 当前 B版如何评估

## 内置固定评测

入口是`RagBEvaluationService`，管理接口为`POST /admin/rag-lab/evaluation/run`和`POST /admin/rag-lab/evaluation/benchmark/run`。读取资源目录中的12题冒烟集及60题基准集，调用实际B版检索，不调用回答生成模型。

主要统计：

- 来源命中：前K是否出现任意一个预期sourceRef。代码名称为SourceRecallAtK，实质是题目级命中率，不是全部相关文档的召回率。
- 通过率：检索策略是否符合预期，是否找到允许的来源类型/指定来源。
- 业务条件与拒答：语言、Docker、数据库、项目周期及来源状态等是否过滤，是否返回预期检索策略。不是实际客服生成回答的拒答准确率。
- 可追溯：返回块是否有合法chunkId和起止位置。
- 引用就绪：是否达到现有程序的证据数量/长度判据，不能证明逐句引用正确。
- P50/P95：该轮实际检索耗时。

2026-09-29报告记录B版60/60通过、带指定来源的53题全部在前8命中；该组题来自已知资料，很多题直接点名项目，而且排序曾依此修正。这不是当前全场景真实准确率，也不是独立盲测。

## 后续140题诊断

`docs/rag-b/m3-full-corpus/native-quality.json`保存90道语义题、50道点名回归。语义题中B版目标来源命中为79/90（87.8%），目标字面原文锚点命中为74/90（82.2%）；同时计算了MRR。点名50题来源命中49/50。

该轮也不是独立盲测。原文锚点只检查某个关键短语，不能代替所有事实与限制的完整标注。文件中的耗时可能与其他流量重叠，不能直接作为此次新增Reranker耗时的对照。

## 最近README专项

最近的三组实验、推荐专项和保守准入V5实验使用单独冻结的README和题集，要求找到具体事实与必要限制；实验统一采用纯向量排序。

其中A组复用B版的全文结构分块，但没有运行B版原生混合检索和全部业务流程。其12/20等分数不应与旧60题的100%直接比较。

## 本轮Reranker对比

固定当前B版，运行相同题目和同一份Top20候选，对比重排前后Top1/3/5/8的来源及原文锚点命中和MRR，并保留所有退步。业务规则单独报告，模型分数只决定排序，不能替代业务条件或证据核实。

候选快照、真实模型请求和请求账本分别保存。此次先验证Top20追加重排的作用；是否改成在最终Top8截断之前对完整融合候选重排，需要后续独立实现与对照。
