## MRR@8

MRR是平均倒数排名（Mean Reciprocal Rank）。对每道问题，找到前8条结果中的第一个相关证据：第1名计1，第2名计1/2，第3名计1/3，第8名计1/8；前8条没有相关证据计0。然后对所有问题取平均。

例如4题的第一个证据分别在第1、2、5名，第四题未在前8命中：MRR@8=(1+1/2+1/5+0)/4=0.425，而Recall@8=3/4=75%。MRR同时受到证据能否进入前8和进入后有多靠前的影响。

箭头↑表示越大越好。0.828不是82.8%的回答准确率，不是平均名次，也不能倒过来计算成平均排名。

本轮语义题相关证据的判定是：来源符合标注且片段包含规范化后的事实锚点。它是可复核的证据代理指标，不是完整事实蕴含检查。旧50题只标来源，排名含义不同，因此主表采用新增60题的证据MRR。

M3-512本轮60/60题在前8出现标注证据，44/60题在第1条出现，MRR@8为0.828。仍没有证明生成回答100%准确，也没有证明全部支持事实都已经召回。
