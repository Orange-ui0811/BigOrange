## 验收定义

- AC-01：范围控制样本正确；不能误排范围内项目，也不能把纯课程、资源集合当作业务项目。
- AC-02：完整代码与必要说明可以一起保留；截断、依赖缺失或冲突仍保持复核。
- AC-03：导航与正文分开，产品、版别、平台与原文一致。
- AC-04：三项质量门槛分别 ≥95% / ≥85% / ≥85%。
- AC-05：标注集中的关键限制误删、范围越界、原文错引和不确定内容误放行为 0。
- AC-06：非法响应、超时、预算耗尽可控；缓存随源文和处理版本变化失效。

范围以内/以外由调用前冻结的标签确定，不能由系统预测结果自行缩小分母。正文知识、导航、范围控制和规则控制分别统计。知识恢复必须检查最终候选及必要依赖；只有模型 KEEP、但无法生成可用候选的内容不能计为恢复。

新版验收建议取 8–12 个未用于此次调参的仓库；数量与批次需在 R4 核查上下文后冻结。它们不是全库随机样本，也不保证统计代表性。标注、源码引用和质量评分分别报告。
