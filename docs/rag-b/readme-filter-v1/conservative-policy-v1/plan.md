# 保守准入 V5：有界修改与原题回归

本轮依据已经完成的三组实验和推荐专项实验修复准入误伤、导航误判、纯标题向量。旧文件与旧结果保留，网站当前索引不切换。

## 交付内容

1. `ReadmeConservativePolicy`：独立事实重新核查依赖。未核实许可单列，不误挡一般功能/安装事实；明确使用限制继续绑定。原始 REVIEW 不直接变为 KEEP。
2. 本机安装声明与只有链接的导航分开；关联产品、版别和未读链接不得作为核心能力证明。
3. `ReadmeApprovedStructuralChunker`：复用 B 版 Token 分块器，原文标题附着正文，纯标题不单独生成向量。每个引用仍保存原文区间和散列；拼装分隔符不伪造原文位置。
4. `ReadmeKnowledgePreparation`：新的实验准备入口，输出准入、条件、知识单元和结构块。没有自动发布、存储或模型调用。

## 回归边界

- 输入仍为已研究的 AnythingLLM、Flowise、n8n、Appsmith、Docguard 五份冻结 README，复用已保存分类。
- 题目完整复用推荐专项 20 道主检索题与 6 道不足观察题，不改答案、不删除仍未准入的事实。
- A 全文结构块不变；新版 B 为相同准入范围的结构块；新版 C 为知识单元块。旧 B/C 同时报出作为历史对照。
- 本轮同时修准入与 B 的表示，不把旧 B 到新 B 的变化全部解释为过滤贡献。
- 相同 bge-m3 版本、正文向量、余弦排名；不加入关键词、查询改写、名称加分、额外重排。
- 每题三组交替检索各三次；检查 Redis 返回候选覆盖及精确余弦 Top10。小样本诊断取全候选后按余弦稳定排序，不作为大库 HNSW 性能基准。
- 报告 Top1/3/5/10、直接片段与知识单元恢复后的 2048 BGE Token 预算。不能截断必要条件，不能从 TopK 以外补取。
- 复用所有旧文档与查询向量，只为新增正文向量请求本地 Ollama。调用前按文本去重、冻结请求清单；批量 8 条、独立账本、无重试，最多 50 次；云端分类/聊天调用为 0。

## 验收与诚实报告

- 对未知前置条件、非生产限制、替代安装路径、导航、源 REVIEW、原文映射和纯标题执行程序回归。
- 验证 A 输入和排名与旧实验一致；新版 B/C 没有越过共同批准范围。未出块内容继续计入遗漏。
- 保留改善和退步题号，并区分准入、供给、排序及预算问题。若未优于 A，如实报告，不能宣布可替换 B 版。
- 助手标注、五仓库、小样本、检索证据回归；不代表独立测试、最终推荐成功率、正确拒答率或商业使用资格。

运行入口：`python scripts/readme_conservative_eval.py prepare/freeze/run/verify`（分别执行对应阶段；已封存后只运行 verify）。
