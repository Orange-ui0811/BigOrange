# 智能分析 A/B 接入对照实验协议

执行日期：2026-10-03。目标是比较当前智能分析保留既有产品逻辑、仅接入不同知识检索后的行为，不是比较两个 Embedding 模型的纯能力，也不是客服模块 A/B。

## 执行边界

- 8 个合成画像，每个分别执行 A、B 两轮，共 32 次生成；交替 AB/BA 顺序，单并发。两轮重复不视为新的独立场景。
- 通过仅开发环境可用、需要管理员鉴权的 `/admin/rag-lab/compare/platform-analysis` 执行真实 `TrendV2Analyzer`。实际调用图谱、学习／职业项目业务服务、检索、Prompt、生成模型、JSON 解析、卡片组装和来源绑定。
- 不读取账号画像或真实聊天历史，不扣平台积分，不保存用户趋势历史，不修改普通入口的 A 路由。
- 未执行普通用户页面的视觉动画、额度扣除、历史落库和路由器重试；因此这是服务端产品生成链路对照，不是 UI 端到端验收或容量测试。前端现有约 2.5 秒动画不计入。
- 使用运行时 `project` 配置：Gitee `DeepSeek-V4-Pro`，配置版本 `1-1785206616703`，不是客服使用的 Flash，也不是环境变量里的 DeepSeek 官方端点。
- 生成参数沿用原平台：`temperature=0.25`、`max_tokens=4096`，未显式指定 thinking；供应商实际返回 reasoning_tokens，单独记录且不与 completion_tokens 重复相加。
- 供应商返回了 `deepseek-v4-pro` 和 `deepseek-v4-pro-ga-260813` 两种标识。除全部样本外，另报同题同轮且返回标识一致的配对子集；不能保证供应商内部权重和服务节点完全冻结。

## A 与 B 的接入方式

| 项目 | A | B 实验接入 |
|---|---|---|
| Embedding | bge-small-zh-v1.5，512 维 | bge-m3，1024 维 |
| 索引 | 当前 default-index | 当前 B HNSW_HYBRID 代际 |
| 分块 | 旧库已有片段 | STRUCTURE_M3_512_768_64_V1 |
| 查询 | 平台原有主题／语言与意图两路查询 | 相同两路查询，分别进入 B 原生混合检索 |
| 候选 | 每路向量 Top50，加旧词面检索与加权融合 | 每路原生 Top8，再按项目聚合最多 3 个片段；路间按排名加权 |
| 后置条件 | 原有 TrendTopicGate 与项目身份检查 | 保留同样主题与身份检查 |
| 输入生成模型 | 最多 3 个知识项目，共不超过 1100 字符 | 相同证据卡格式与长度预算 |
| 其他候选 | 真实学习／职业业务服务提供 | 同样业务服务，独立于知识检索 |

B 接入仍受旧智能分析的关键词过滤和证据压缩约束，不等同于 B 客服的严格项目查询、完整证据说明或最优 B 接入方案。它回答的是“直接接入后会怎样”，不能推导 B 检索能力的上限。

## 数据规模与公平性

A MySQL 有 572 篇资料，其中 vector_status=DONE 为 491，GitHub PENDING 为 81；Redis 有 5647 个向量条目。B 有 565 篇 READY 文档，活跃版本片段合计 8660，Redis 对应 8660 条。B 比 A 多覆盖一部分旧库尚未完成向量化的资料，因此不是同文档模型消融实验。

B 代际表保留的 document_count=219、chunk_count=6227 是旧构建统计，不能当作增量写入后的当前规模。报告使用活跃文档／片段与 Redis 实测统计。

源代码哈希见 `code-manifest.json`，索引／模型快照见 `before.json`、`after.json`；内容统计校验见 `audit-start.json` 和最终审计。各次原始结果独立保存，不筛掉失败调用。

## 内容与成本的判定方式

- 内容逐场景核对目标适配、证据支持、建议可操作性、信息不足处理与重复稳定性；不把模型自己输出的 score 当质量得分。
- 来源绑定检查只证明推荐 URL 属于本次知识证据或业务候选，不证明全部功能、难度、时长和市场判断为真。引用编号有效率不能叫回答准确率。
- 未建立本轮独立人工金标准，未运行 RAGAS 或额外模型裁判，因此不报告虚构的 Recall、MRR 或“回答准确率”。
- 耗时分为检索、模型与本地 HTTP 总耗时。小样本均值／中位数／最大值只反映本轮请求，不作为生产 P95 承诺。
- 用量取供应商返回的输入、输出、思考及缓存 Token。金额按请求 SKU `DeepSeek-V4-Pro` 公开标价输入 12 元／百万、输出 24 元／百万估算；缓存优惠、资源包折扣和供应商结算未核验，属于统一标价对照，不是实际账单。
- 返回 GA 标识不直接改用另一 SKU `DeepSeek-V4-Pro-0813` 的价格；汇总原始行保留其输入 9 元／百万、输出 27 元／百万的敏感性估算，防止混用两者。
- Gitee 官方目前声明 Embedding 免费；不将接口缺少 Token 用量误写成消耗了 0 Token。此次没有重建索引或翻译入库，存储、服务器与既有入库费用不计入单次生成费。
