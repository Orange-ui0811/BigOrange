## 2. 设计系统重建

### 2.1 设计令牌（theme.css）

基于原型 HTML 的 CSS Variables 体系，完全替换旧版像素极简系统：

| 类别 | 关键变量 | 值 |
|------|---------|-----|
| 品牌色 | `--brand` / `--brand-strong` | `#f37021` / `#ea580c` |
| 暖色辅助 | `--cream` / `--brown` / `--gold` | `#fff7ed` / `#5c260f` / `#f59e0b` |
| 圆角 | `--radius-xl` / `--radius-lg` / `--radius-md` / `--radius-pill` | `28px` / `20px` / `14px` / `999px` |
| 投影 | `--shadow-pixel` / `--shadow-card` / `--shadow-lift` | 像素偏移 + 轻阴影 |
| 边框 | `--border-orange` / `--border-weak` | `#fed7aa` / `rgba(254,215,170,.5)` |
| 表面 | `--surface-warm` / `--card-featured` | `#fefaf5` / `#fffdf7` |
| 字体 | `--font-mono` / `--font-body` | `"Courier New","SimHei",monospace` / `"Microsoft YaHei","PingFang SC",sans-serif` |

**Body 背景**：三重 `radial-gradient` 暖橙光晕 + `linear-gradient` 像素网格底纹（18px 间距）+ 右下角暖光晕 `::after`

**Element Plus 全局覆写**：按钮/输入框/卡片/表格/标签/Tabs/菜单/分页/对话框全部对齐原型圆角和暖色系

## 5. UI/UX 精修（ui-ux-pro-max Skill 驱动）

基于 `.codex/skills/ui-ux-pro-max` 数据库分析（Creator Economy Platform 匹配，Soft UI Evolution + Vibrant & Block-based 风格）：

| 类别 | 改前问题 | 改善措施 |
|------|---------|---------|
| **间距** | 区块间距 16-20px，缺少呼吸感 | 区块间距 → **28px**，网格间距 → **20px**，内容区 padding → **24/32px** |
| **投影** | 双层像素阴影 `4px+8px` 太重 | 减为单层 `shadow-card`（`0 8px 24px rgba(...,.05)`），hover 展开 |
| **卡片层次** | 所有卡片同白底同边框 | 三级系统：L1 渐变+4px 橙左线，L2 暖底+3px 暖橙左线，L3 白底+3px 弱左线 |
| **卡片内边距** | 14-20px 不一致 | 统一 18-20px |
| **阶段导航** | `flex-wrap: wrap` 导致换行宽度不均 | 移除 wrap，6 阶段始终一行等宽，文字超出 ellipsis 截断 |
| **SubmitJob 布局** | 右栏 `0.7fr` 导致大面积空白 | 改为固定 `300px`，左右面板分别应用 L1/L2 卡片层次 |

## 8. 设计决策记录

| 决策 | 结论 | 原因 |
|------|------|------|
| 圆角风格 | 采用原型大圆角（14-28px） | 用户明确要求「和 HTML 一模一样」 |
| 导航结构 | 14 项压缩为 5 项 + Hub 子页 | 原型信息架构，用户确认 |
| 发布流程 | 选择页 → 表单双模式 | 原型分流设计，保留现有表单功能 |
| 卡片层次 | 三级视觉权重（L1/L2/L3） | ui-ux-pro-max 诊断：原设计缺少主次区分 |
| 左侧栏尺寸 | 252px，对齐原型 | 原型 `grid-template-columns: 252px 1fr` |
| 右侧空白 | 去掉所有 `max-width` 限制 | 原型全宽布局 |
