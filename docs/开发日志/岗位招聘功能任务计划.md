## Phase 1: 数据层 + 导入脚本

> **目标**：建表 + Entity + Mapper + 43 篇已有 MD 批量导入

### 1.1 建表

**输入**：需求文档

**产出物**：`schema-v1.sql` 追加：

```sql
CREATE TABLE IF NOT EXISTS job_posting (
    id              BIGINT       NOT NULL AUTO_INCREMENT,
    company         VARCHAR(128) NOT NULL COMMENT '公司名（存储用，不对外展示）',
    position        VARCHAR(256) NOT NULL COMMENT '岗位名称',
    direction       VARCHAR(64)           COMMENT '技术方向（对应14个topic）',
    content         MEDIUMTEXT   NOT NULL COMMENT 'JD原始内容',
    display_content MEDIUMTEXT            COMMENT '合规展示用内容（已剥离公司名）',
    audit_status    VARCHAR(16)  NOT NULL DEFAULT 'PENDING' COMMENT 'PENDING/APPROVED/REJECTED',
    submitter_id    BIGINT       NOT NULL COMMENT '投稿人ID',
    submitter_ip    VARCHAR(64)           COMMENT '投稿IP',
    submitter_role  VARCHAR(16)           COMMENT '投稿人角色',
    reject_reason   VARCHAR(512)          COMMENT '拒绝原因',
    create_time     DATETIME     NOT NULL DEFAULT CURRENT_TIMESTAMP,
    PRIMARY KEY (id),
    UNIQUE KEY uk_company_position (company, position),
    KEY idx_direction (direction),
    KEY idx_audit_status (audit_status),
    KEY idx_submitter (submitter_id)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_unicode_ci COMMENT='岗位招聘信息';
```

**设计要点**：
- `company` 和 `position` 保留在存储层但不在 API 响应中返回
- `display_content` 是给前端展示的版本，已剥离公司名和元信息
- `submitter_ip` 和 `submitter_role` 用于侵权追溯

@Transactional
public void approve(Long id, Long adminId) {
    JobPosting jp = jobPostingMapper.selectByIdForUpdate(id);
    if (!"PENDING".equals(jp.getAuditStatus())) throw new BaseException("状态不正确");

    // ① 更新状态
    jobPostingMapper.updateAuditStatus(id, "APPROVED", null);

    // ② 向量化入库
    documentService.importFromJobPosting(jp);

    // ③ 发奖励
    quotaService.grantReward(jp.getSubmitterId(), 50, "岗位投稿审核通过奖励");

    // ④ 飞书通知（不含个人信息）
    feishuNotifyService.send("岗位投稿审核通过：" + jp.getPosition());
}

## Phase 5: 岗位匹配（AI 匹配）

> **目标**：方案设计完成后可匹配岗位

### 5.1 JobMatchService

**产出物**：`orange-server/.../service/JobMatchService.java`

**核心逻辑**：

```java
public List<JobMatchResult> matchJob(String planContent, Long accountId) {
    // ① 配额检查
    String requestId = "match_" + accountId + "_" + System.currentTimeMillis();
    quotaService.consume(accountId, 50, "岗位匹配", requestId);

    try {
        // ② 向量检索：在知识库中搜索相关岗位 JD
        List<Document> jobDocs = vectorStore.similaritySearch(
            SearchRequest.builder()
                .query(planContent)
                .topK(5)
                .similarityThreshold(0.5)
                .filterExpression("source == 'JOB_POSTING'")
                .build()
        );

        // ③ 组装 prompt
        String prompt = buildMatchPrompt(planContent, jobDocs);

        // ④ 调 AI
        String aiResult = callAI(prompt);

        // ⑤ 解析 JSON + 过滤公司名
        return parseAndSanitize(aiResult);
    } catch (Exception e) {
        quotaService.refund(accountId, 50, requestId, "岗位匹配失败退款");
        throw e;
    }
}
```

**Prompt 设计要求**：
- 只基于提供的 JD 列表推荐，不要编造岗位
- 返回结构化 JSON：`{ matches: [{position, reason, focus}] }`
- 明确要求不返回公司名

## 3. 全局技术约定

### 公司名三重过滤

```
① 入库时过滤：用户投稿 + 导入脚本 → stripCompanyName()
② 返回时过滤：API 响应只取 display_content，不取 company 字段
③ 匹配时过滤：AI 返回的 JSON 后端正则再过滤一遍已知公司名
```

### 符合避风港的运营红线

```
① 管理员账号不能投稿（role=ADMIN → 拒绝）
② 审核通过后 JD 原文不可修改（PATCH disabled）
③ 所有投稿记录 submitter_ip/submitter_role 永久留存
④ 用户协议注册时必须勾选同意
```
