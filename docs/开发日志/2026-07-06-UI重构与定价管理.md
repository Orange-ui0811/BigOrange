## 3. 定价管理系统

### 3.1 需求背景

管理员需要在后台统一管控用户端 AI 服务消费金额，替代 4 处硬编码（趋势 V1=50, 趋势 V2=50, 方案设计=40, 岗位匹配=50）。

### 3.2 架构方案

```
Admin Pricing.vue → POST /admin/pricing/save
  → AdminPricingController（校验 1~10000）
    → PricingService.updateCost()（写 MySQL + 审计日志 + 刷新内存缓存）
      → 消费端通过 PricingService.getCost(key) 读取
```

MySQL 主存储，内存 ConcurrentHashMap 热缓存，`@PostConstruct` 启动加载。

## 5. Bug 修复

### 5.1 GitHub 周榜周一数据为空

**现象**：切换到 GitHub 数据源 + 本周时段，数据显示为空。

**原因**：`LeaderboardRefreshTask.refreshAll()` 使用 `today.with(TemporalAdjusters.previousOrSame(DayOfWeek.MONDAY))` 计算周一日期。周一当天运行时 `previousOrSame` 返回当天（2026-07-06），GitHub 查询变成 `created:>2026-07-06`，仅搜索当天创建的仓库，结果几乎为空。

**周一到周日影响分析**：
- 周一：`previousOrSame` = 今天 → 只搜 1 天 ❌
- 周二~周日：`previousOrSame` = 本周一 → 搜 1~6 天 ✅

**修复**：`LeaderboardRefreshTask.java:69`
```java
// 之前
LocalDate monday = today.with(TemporalAdjusters.previousOrSame(DayOfWeek.MONDAY));

// 之后
LocalDate monday = today.with(TemporalAdjusters.previousOrSame(DayOfWeek.MONDAY));
if (monday.equals(today)) monday = monday.minusWeeks(1); // 周一用上周一
```

当日空快照已通过 `DELETE FROM leaderboard_snapshot WHERE period='week' AND snapshot_date='2026-07-06'` 清除，等待重启后重新拉取（当前 GitHub API DNS 解析临时不可用）。

### 5.2 SVG 高光不可见

**原因**：高光 `<rect>` 在身体渐变 `<rect>` 之前渲染，被后续绘制的身体覆盖。

**修复**：将 4 个高光 `<rect>` 移动到身体渐变之后、眼睛之前。

### 5.3 Pricing.vue 多余闭合标签

编译错误 `Invalid end tag`，文件末尾误写 `</template>` 闭合标签，已删除。
