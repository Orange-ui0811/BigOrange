# 2026-06-27：RAG 知识库优化

> **会话摘要**：优化知识库采集机制、解决中英文跨语言检索问题、完善管理端知识库页面。

---

## 1. 中英文跨语言检索修复

### 问题发现

`bge-small-zh-v1.5` 对中文 query ↔ 英文 README 的相似度仅 **0.505**，低于检索阈值 0.6，34 篇英文 GitHub README 对中文用户查询几乎无用。

### 方案对比

| 方案 | CN↔EN 相似度 | 结论 |
|------|-------------|------|
| A: 当前 bge-small-zh | 0.505 | ❌ 低于 0.6 |
| B: 换 bge-m3 | 0.480 | ❌ 更差 |
| C: 吞入时加中文标签 | 0.606 | ✅ 刚好跨过 0.6 |
| **最终：整篇翻译为中文** | **0.80+** | ✅ 最佳 |

### 实现

- `DocumentServiceImpl.translateReadme()`——调 DeepSeek V4 Pro 翻译 README 全文
- 保留 Markdown 结构和代码块
- 翻译失败降级使用原文
- 成本：每个 README ~1 次 LLM 调用

## 2. 采集机制升级

### 旧机制

- 只取 "all" 周期 Top 3
- 无清理机制
- README 不翻译

### 新机制

| 周期 | 数量 | source_ref 格式 | 生命周期 |
|------|------|----------------|---------|
| all（全时段） | Top 20 | `owner/repo` | **永久保留** |
| week（每周） | Top 3 | `owner/repo\|week` | **30 天自动清理** |

清理在 `LeaderboardRefreshTask.refreshAll()` 末尾执行——删 30 天前 `source='GITHUB' AND source_ref LIKE '%|week'` 的文档 + 对应向量。

## 3. 管理端知识库页面优化

### 新增功能

| 功能 | 说明 |
|------|------|
| 内容预览 | 点击文档标题弹窗显示翻译后的中文全文（Markdown 渲染） |
| 生命周期标签 | `永久`（蓝色）/ `30天后清理`（橙色） |
| 统计概览 | 顶部四卡片：文档总数 / GitHub 采集 / 手动上传 / 总切片数 |
| 标题搜索 | 输入即过滤 |
| Markdown 渲染 | 弹窗内 `#`/`##` 标题、`**`加粗、链接可点击 |

### 后端新增 API

| 端点 | 用途 |
|------|------|
| `GET /admin/knowledge/document/stats` | 统计概览 |
| `GET /admin/knowledge/document/{id}` | 查看文档内容（含翻译后全文） |

### 数据库变更

`knowledge_document` 表新增 `content MEDIUMTEXT` 字段——存储翻译后的完整内容。

## 4. 修复的问题

| 问题 | 修复 |
|------|------|
| 本地 Redis 端口冲突（Windows Redis 3.0 占 6379） | Docker Redis Stack 改用 **6380**，`application-dev.yml` 同步 |
| VectorStore Bean 创建时 Docker 未开导致应用崩溃 | 排除自动配置 + `@PostConstruct` 状态报告 |
| `splitChunks` 死循环（小文本） | 加 `end >= text.length()` 提前退出 |
| INSERT 不写 content 字段 | Mapper XML 补上 `content` 列 |
| 标题提取取到 badge/MD 链接 | 跳过 `# [` 开头的行 |
| README 拉取无超时 | `readmeRestTemplate` 加 10s connect/read timeout |
| 大文本 embedding 400 错误 | `sanitizeChunks` 截断 400 字 + 过滤纯符号片段 |

## 5. 关键配置变更

### application-dev.yml

```yaml
spring.data.redis:
  client-type: jedis
  host: localhost
  port: 6380              # 原 6379 → 6380（避开 Windows Redis）
spring.ai.vectorstore.redis:
  initialize-schema: true  # 必须！默认 false
```

### application-prod.yml

同上，`initialize-schema: true`，端口保持 6379。
