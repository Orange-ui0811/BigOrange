| 组件 | 旧 | 新 | 操作 |

| Spring Boot | 2.7.18 jar | 3.3.5 jar | 本地 mvn 构建 → 上传 → 替换 |

### 2.2 部署过程中修复的问题（10 个）

| # | 问题 | 根因 | 修复 |
|---|------|------|------|
| 1 | 后端崩溃 `JavaMailSender bean not found` | `application-prod.yml` 缺少 `spring.mail` 配置段 | 补上邮件 SMTP 配置 |
| 2 | `email` 列不存在 | 本地手动 ALTER TABLE 未同步到服务器 | `ALTER TABLE account ADD COLUMN email, ADD UNIQUE KEY` |
| 3 | 定价表 `ai_service_pricing` 不存在 | schema-v1.sql 导入被 duplicate admin 中断 | 手动单独建表 |
| 4 | 图片 404 | Nginx 图片正则 `~ .*\.(png)$` 优先于普通 `/uploads/` | `/uploads/` 加 `^~` 前缀 |
| 5 | 图片 403 | Nginx（nginx 用户）无 `/root/` 读权限 | `chmod 755 /root && chmod -R 755 /root/uploads` |
| 6 | 图片 URL 拼接错误 | 生产环境 `API=/api`，`API+form.coverUrl` → `/api/uploads/xxx` | 改为直接用 `form.coverUrl`（4 个文件） |
| 7 | 管理端图片不显示 | 同上 | `orange-admin/WorkDetail.vue` 同步修复 |
| 8 | 头像不显示 | `MainLayout.vue` + `EditProfile.vue` 用 `API+` 拼接 | 改为直接路径 |
| 9 | Turnstile 测试 key | 本地用 `1x00000...`，服务器需真实 key | `.env` 设 `VITE_TURNSTILE_SITE_KEY`，start.sh 设 `TURNSTILE_SECRET_KEY` |
| 10 | `@PostConstruct` 自动爬取 | 每次重启都触发完整爬取 | 移除 `@PostConstruct`，仅保留周一凌晨 2:00 `@Scheduled` |

### 2.3 数据库同步

- 导出本地全量 `orangejd_backup.sql`（6.6MB）→ 导入服务器
- ⚠️ **教训**：全量导入会覆盖服务器用户数据！日常更新必须只用 `schema-v1.sql`（`CREATE IF NOT EXISTS`）

### 2.4 Nginx 关键配置

```nginx

location ^~ /admin { alias /data/www/orangejd/admin; try_files $uri /admin/index.html; }
```

## 3. 游戏式引导教程

### 3.1 PageTour.vue 组件

**视觉效果**：半透明遮罩 + 元素镂空聚光灯 + 金色脉动边框 + 像素橙子说话气泡

**技术实现**：
- `Element.getBoundingClientRect()` 实时定位
- `box-shadow: 0 0 0 9999px rgba(0,0,0,.35)` 实现镂空
- 气泡四方向自动避让（bottom/top/right/left），`Math.min/max` 防溢出
- `pointer-events: none` 遮罩不挡交互
- `localStorage` 分用户记录（`tour_done_xxx_<userId>`）
- 轮询启动：150ms × 30 次，等待异步元素渲染

**表达式系统**（6 种）：
| 表情 | 场景 |
|------|------|
| 😊 smile | 一般说明 |
| ✨ sparkle | 兴奋/推荐 |
| 😉 wink | 俏皮/交互 |
| 👀 curious | 好奇/探索 |
| 🤩 amazed | 惊叹/亮点 |
| 🥰 love | 喜爱/个人 |

### 3.2 覆盖页面（12 页，38 步）

| 页面 | storageKey | 步骤数 | 关键高亮 |
|------|-----------|--------|---------|
| 趋势分析 | `tour_done_trend` | 6 | 全景图/时间切换/详情卡/洞察结果/智能分析面板/Tab |
| 方案设计 | `tour_done_plan` | 4 | 想法输入/模式选择/阶段导航/编辑按钮 |
| AI 工具 | `tour_done_aihub` | 3 | Hub Hero/Ticker 滚动/三大入口卡 |
| 榜单 | `tour_done_leaderboard` | 3 | 筛选栏/Tab/排名卡 |
| 发布 | `tour_done_publish` | 3 | 发布选择/审核流程/MVP 边界 |
| 市场 | `tour_done_market` | 3 | 搜索条/内容筛选/作品卡 |
| 消息 | `tour_done_chat` | 3 | 会话列表/输入区/沟通摘要 |
| 我的 | `tour_done_mehub` | 3 | 个人信息/我的作品/功能网格 |

### 3.3 迭代过程

| 版本 | 问题 | 修复 |
|------|------|------|
| v1 | 遮罩挡住整个页面，无法点击和滚动 | 遮罩加 `pointer-events: none`，气泡加 `pointer-events: auto` |
| v2 | 元素异步加载，600ms 启动太早找不到 | 改为轮询 150ms × 30 次（最长等 4.5s），找不到不显示 |
| v3 | 滚动时气泡错位 | 加 `window.addEventListener('scroll', ...)` |
| v4 | 定位延迟大，不跟手 | debounce 从 50ms 降到 10ms |
| v5 | 换用户登录后引导消失 | storageKey 拼入 `sessionStorage.myId`，每个用户独立记录 |
| v6 | 气泡超出屏幕，点不到按钮 | 四方向都加 `Math.min/max` 边界限制 |

## 4. 知识库修复

| # | 问题 | 根因 | 修复 |
|---|------|------|------|
| 1 | `new` 文档被标为「永久」 | `resolvePeriod()` 只认 `|week`，不认 `|new` | 三处同步加 `|new` 判断 |
| 2 | `new` 文档永不清理 | 清理 SQL `LIKE '%|week'` 漏了 `|new` | 改为 `LIKE '%|week' OR LIKE '%|new'` |
| 3 | 同一 repo 重复入库 | `importFromGithub` 的 sourceRef 对 `new` 期不加后缀 | 改为 `("new"\|"week").equals(period)` |
