# 2026-07-01：安全增强 + 平台改善（New API 对比借鉴）

> **会话摘要**：基于 New API/Sub2API 项目对比，实施安全防护、可观测性、管理审计、用量统计等 7 项改善。

---

## 1. SSRF 防护

**文件**：`orange-common/.../util/UrlValidator.java`

- 拦截内网 IP（`isSiteLocalAddress` / `isLoopbackAddress` / `isLinkLocalAddress`）
- 白名单直通：阿里云 OSS、GitHub、Gitee 域名
- 接入点：`AiAuditService.callAi()` —— 审核时收集图片 URL 前校验

---

## 2. Token 前缀 `sk-`

**文件**：`orange-common/.../utils/JwtUtil.java`

- `createJwt()` 生成的 JWT 自动带 `sk-` 前缀
- `parseJwt()` 兼容新旧格式（自动去前缀）
- 旧 token 在过期前仍可正常使用，无需用户重新登录

---

## 3. Request ID 全链路追踪

**文件**：`orange-server/.../interceptor/RequestIdInterceptor.java`

- 每个请求生成 8 位 UUID
- 放入 MDC（日志自动带上）+ 响应头 `X-Request-Id`
- 注册于 `WebMvcConfiguration.addInterceptors()`

---

## 4. `/health/detail` 增强

**文件**：`orange-server/.../controller/HealthController.java`

新增 `/health/detail` 端点返回：
```json
{"db":"UP","redis":"UP","rag_vector_store":"UP"}
```

---

## 5. 管理操作审计日志

**文件**：`orange-server/.../aspect/AdminAuditAspect.java`

- AOP 切面拦截所有 `/admin/**` 的 POST/PUT/DELETE 操作
- 记录：adminId / action / IP / 参数
- 输出到独立的 `ADMIN_AUDIT` logger

---

## 6. 用量统计仪表盘

**后端**：`orange-server/.../controller/admin/AdminStatsController.java`
- `GET /admin/stats/quota-usage?days=7` —— 按天 + 按模块聚合统计

**前端**：`orange-admin/src/views/UsageStats.vue`
- 概览卡片：总消耗 / 总充值 / 调用次数 / 退款次数
- 按天统计表格 + 按模块统计表格
- 路由：`/usage`，侧边栏「用量统计」

---

## 7. AI 调用设置管理页

**后端**：`orange-server/.../controller/admin/AdminAIConfigController.java`
- 读取/保存 AI 配置到 Redis（即时生效，无需重启）

**前端**：`orange-admin/src/views/AIConfig.vue`
- 趋势分析 / AI 审核 / RAG Embedding / 榜单抓取 四个模块的配置展示
- 编辑 + 保存，API Key 脱敏显示
- 路由：`/ai-config`，侧边栏「AI 调用设置」

---

## 8. 配额系统消费确认弹窗修复

**文件**：`orange-web/src/views/TrendAnalysis.vue` / `PlanDesigner.vue`
- 添加 `ElMessageBox` import
- 趋势分析：开始前弹窗「本次将消耗 50 segments」
- 方案设计：每阶段前弹窗「本阶段将消耗 40 segments」

---

## 9. 公开端点配额消费修复

**文件**：`AppTrendController.java` / `AppPlanController.java`
- 趋势分析和方案设计是公开端点，JWT 拦截器不生效
- 改为手动从 `App-Token` 请求头提取用户身份
- 返回的 JSON 中包含 `balance` 字段（余额）
