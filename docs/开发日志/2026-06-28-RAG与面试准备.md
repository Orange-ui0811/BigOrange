## 1. 趋势分析 RAG 开关

### 需求

智能分析页面加开关——用户可选择是否启用知识库增强。

### 实现

- `TrendProfileDTO` 加 `Boolean useRag` 字段
- `TrendAnalysisService.analyzeV2()` 加参数 `Boolean useRag`——为 true 时才调 `buildRagContext()`
- 前端第四步表单加 `el-switch` 组件 + tooltip 说明
- JSON 序列化修复：`topics` 和 `languages` 加 `Array.isArray()` 保护，防止历史记录加载时字符串化
