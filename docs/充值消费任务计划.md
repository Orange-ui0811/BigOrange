## Phase 2: 核心服务层

> **目标**：QuotaService 提供 consume/recharge/refund/getBalance，所有 AI 消费模块只依赖此接口

### 2.1 QuotaService 接口

**输入**：Phase 1 的 Mapper

**产出物**：`orange-server/.../service/QuotaService.java`

```java
public interface QuotaService {
    /** 消费配额（原子扣减 + FOR UPDATE） */
    int consume(Long accountId, int amount, String description, String requestId);

    /** 充值配额（原子增加 + 写日志） */
    int recharge(Long accountId, int amount, String source, String description);

    /** 退款配额（reverse consume） */
    int refund(Long accountId, int amount, String requestId, String description);

    /** 查询余额 */
    long getBalance(Long accountId);
}
```

### 2.2 QuotaServiceImpl 实现

**产出物**：`orange-server/.../service/impl/QuotaServiceImpl.java`

**核心实现**：

```java
@Transactional
public int consume(Long accountId, int amount, String description, String requestId) {
    // ① requestId 幂等检查
    if (quotaLogMapper.existsByRequestId(requestId)) {
        Account acc = accountMapper.selectById(accountId);
        return (int) acc.getQuota();
    }
    // ② FOR UPDATE 锁行
    Account acc = accountMapper.selectByIdForUpdate(accountId);
    // ③ 原子扣减（返回 0 表示余额不足）
    int rows = accountMapper.decreaseQuota(accountId, amount);
    if (rows == 0) throw new BaseException("余额不足");
    // ④ 写日志
    long balance = acc.getQuota() - amount;
    quotaLogMapper.insert(new QuotaLog(accountId, "CONSUME", -amount, balance, source, description, requestId));
    return (int) balance;
}
```

**预消耗→结算模式**（趋势分析专用）：

```java
// ① 预估消费
int estimated = estimateCost(model); // 50 segments
consume(accountId, estimated, "趋势分析预扣", requestId);

// ② 调 AI
try {
    AIResult result = callAIApi(prompt);
    return result;
} catch (AIException e) {
    // ③ 失败退款
    refund(accountId, estimated, requestId, "趋势分析失败退款");
    throw e;
}
```

### Phase 2 验证

- [ ] `consume(1, 50)` → `SELECT quota FROM account WHERE id=1` → 减少 50
- [ ] `quota_log` 表新增一条 type=CONSUME 记录

- [ ] 余额不足时 `decreaseQuota` 返回 0 → 抛 BaseException

```java
@PostMapping("/generate")
public Result<List<String>> generate(@RequestBody Map<String, Object> body) {
    int count = (int) body.getOrDefault("count", 10);
    int quota = (int) body.getOrDefault("quota", 500);
    Long adminId = BaseContext.getCurrentId();

    List<String> codes = new ArrayList<>();
    for (int i = 0; i < count; i++) {
        String code = generateRandomCode(48); // crypto random
        redemptionCodeMapper.insert(new RedemptionCode(code, quota, adminId));
        codes.add(code);
    }
    return Result.success(codes);
}
```

|------|------|

**核心逻辑——创建支付**：

```java
@PostMapping("/create")
public Result<String> createPayment(@RequestBody Map<String, String> body) {
    Long accountId = BaseContext.getCurrentId();
    BigDecimal money = new BigDecimal(body.get("amount"));
    String method = body.getOrDefault("method", "wxpay");

    // 生成唯一 tradeNo
    String tradeNo = "EPAY_" + accountId + "_" + UUID.randomUUID().toString().substring(0, 12);

    // 写 top_up 表（status=pending）
    TopUp topUp = new TopUp(accountId, money * 100, money, tradeNo, method, "epay");
    topUpMapper.insert(topUp);

    // 调 Epay SDK 获取支付链接
    String payUrl = epayService.createPayment(tradeNo, money, method);
    return Result.success(payUrl);
}
```

**核心逻辑——回调**：

```java
@PostMapping("/notify")
public String notify(HttpServletRequest request) {
    Map<String, String> params = parseParams(request);

    // ① 验签
    if (!epayService.verify(params)) return "fail";

    // ② 取本地订单号
    String tradeNo = params.get("out_trade_no");

    // ③ 事务：FOR UPDATE + 状态检查 + 加配额
    topUpService.completeTopUp(tradeNo, params);
    return "success";
}
```

**`completeTopUp` 实现**：

```java
@Transactional
public void completeTopUp(String tradeNo, Map<String, String> params) {
    // FOR UPDATE 锁订单行
    TopUp topUp = topUpMapper.selectByTradeNoForUpdate(tradeNo);
    if (!"pending".equals(topUp.getStatus())) return; // 幂等

    // 更新订单状态
    topUpMapper.updateStatus(tradeNo, "success");

    // 加配额（source=EPAY）
    quotaService.recharge(topUp.getAccountId(), topUp.getAmount(), "EPAY",
        "Epay 在线充值 " + topUp.getMoney() + " 元 → " + topUp.getAmount() + " segments");
}
```

## Phase 7: 验证 + 回归测试

> **目标**：全链路验证 + 并发安全测试 + 回归确认

### 验证矩阵

| 场景 | 预期 | 验证方式 |
|------|------|---------|
| 注册新用户 | quota=100（试用额度） | curl 注册 → `SELECT quota FROM account` |
| 余额充足 + 趋势分析 | 扣 50 → 返回结果 + balance | Postman + SQL 验证 |
| 余额不足 + 趋势分析 | 返回"余额不足" | Postman |
| 同一 requestId 重放 | 不重复扣 | 脚本两次相同请求 |
| 并发 10 用户同时消费 | 余额不为负数 | `ab` 压测 + SQL 检查 |
| AI 失败退款 | 余额恢复 | 模拟 AI 500 → quota_log type=REFUND |
| 充值码兑换 | quota 增加 + 码状态变更 | Postman |
| Epay 回调验签失败 | 返回 fail → quota 不变 | 伪造签名 curl |
| 注册正常 | 不受 quota 默认值影响 | curl 注册 |
| 知识库 API 正常 | 不受新表影响 | curl list |

## 3. 全局技术约定

### 并发安全

```java
// ✅ 正确：原子 SQL
@Update("UPDATE account SET quota = quota - #{amount} WHERE id = #{id} AND quota >= #{amount}")
int decreaseQuota(@Param("id") Long id, @Param("amount") int amount);

// ❌ 错误：read-modify-write
Account acc = accountMapper.selectById(id);
acc.setQuota(acc.getQuota() - amount);
accountMapper.update(acc);
```

### 审计日志

每笔配额变动**必须**写入 `quota_log`。字段要求：`account_id`、`type`、`amount`、`balance`（变动后）、`source`、`description`、`request_id`。

### 错误码

| 场景 | 返回 |
|------|------|
| 余额不足 | `Result.error("余额不足，当前 X segments，需 Y segments")` |
| 充值码无效 | `Result.error("充值码不存在或已过期")` |
| 充值码已使用 | `Result.error("此充值码已被使用")` |
| Epay 验签失败 | HTTP 文本 `"fail"` |
| 兑换频率超限 | `Result.error("操作频繁，请稍后重试")` |
