Reranker 使用 Gitee `bge-reranker-v2-m3`，在业务过滤、去重之后，对最多 80 条候选按每批 20 条重排，再执行多样性选择和 TopK。整轮共享 5 秒超时；任一批失败则整体回退。原融合分数和模型分数分别保存在 `score`、`rerankScore`。

本次接入验收记录：69 项相关 Java 单测通过；8 道真实接入回归通过，包含两个禁用开关基线检查和三个业务策略检查；本地后端 HTTP 检索确认 `APPLIED`。这不是完整平台全量测试，也不是最终生成答案准确率评测。详细范围、失败记录与修正见 `docs/rag-b/reranker-integration-v1/`。

本地 `.env.local`、密钥、模型运行程序和权重、数据库与 Redis 数据、上传文件、运行日志及无关研究目录不属于此快照。Git 中的配置示例默认关闭可选功能；使用时需配置自己的环境。不会因拉取该分支自动获得本地已经入库的知识。

部分真实验收脚本依赖本机数据库、外部模型和被忽略的实验工作目录；仓库中的评测材料用于代码审阅与历史对照，不表示从干净克隆可直接重放全部真实调用。Reranker 的配置、回退及运行说明见 `docs/rag-b/reranker-integration-v1/README.md`。
