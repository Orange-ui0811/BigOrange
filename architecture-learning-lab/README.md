# OrangeVC 个人架构学习工作台

这是一个与 OrangeVC 产品前端完全解耦的个人架构学习页面。内容基于当前仓库代码、Flyway、配置、发布脚本和架构文档，不会进入平台路由、导航、登录或部署流程。

## 打开方式

直接双击 `index.html` 即可打开，不需要安装依赖，也不需要启动本地服务。

如果 Windows 没有关联默认浏览器，也可以双击 `start-learning.cmd`。

## 文件说明

- `index.html`：页面结构
- `styles.css`：高密度架构研修台样式
- `platform-architecture.js`：四张知识图谱、代码索引和故障场景
- `study-sources.js`：两份学习文档合并后的 39 个知识点、160 个网页入口和源码证据
- `content.js`：六条调用链与练习内容
- `career-track.js`：岗位证据矩阵、事实边界、回答卡和升级路线
- `learning-workbench.js`：今日任务、六个实验室、证据门槛和递进式面试数据
- `app.js`：图谱、节点详情、代码阅读和本地进度交互

学习进度只写入浏览器本地存储，不连接 OrangeVC 后端。

## 当前学习闭环

- 模块分页：顶部导航将总览、研修、岗位、图谱、调用链、代码、故障、练习和面试分开显示，URL锚点可直接定位并保留返回路径。
- 全局搜索：按组件、业务、表名、文件和故障关键词定位内容。
- 四级掌握度：看过、理解、串联、掌握，首页汇总并可继续上次位置。
- 知识图联动：节点可进入相关代表链路，源码入口优先定位到对应代码片段。
- 链路代码同步：点击链路步骤会切换到相应 Controller、Service、Mapper 或迁移文件。
- 分层详情：快速理解、深入设计、工程推演、代码关系和面试追问按需展开。
- 主动练习：选择题、开放故障推演、个人笔记和模块化面试演练均保存在本机。
- 图谱工具：节点类型筛选、直接关系聚焦、历史返回、缩放和列表模式。
- 今日研修：从未完成任务中选择三项，关联实验、预计时间和应留证据。
- 专题实验室：Runtime、MCP、Tracing、Context Window、Kubernetes与DAG六个训练主题。
- 证据解锁：代码、测试、日志、截图或复盘齐全后，才将能力声明升级为“可以写”。
- 递进式面试：按照约束、机制、失败、权衡和证据五个维度进行100分自评。

Runtime和MCP实验室对应仓库已有能力；Tracing、Context Window、Kubernetes和DAG属于研修实验。界面会明确显示这一边界，完成模拟不等同于生产实现。

## AI Agent 系统平台岗位训练

研修台包含一条独立的岗位对齐轨道：

- 将 Runtime、Tool/MCP、编排、可观测性、分布式状态、LLM API 和云原生要求映射到真实仓库证据。
- 明确区分“强证据”“部分对应”和“需要补课”，避免把未实现能力包装成项目成果。
- 深挖持久化任务运行时、AI调用治理、安全工具调用、Ingestion工作流和执行轨迹。
- 提供四个项目故事、十二个高频追问和五个需要留下验证证据的动手实验。
- 明确当前没有完整上下文窗口管理、动态插件沙箱、通用DAG、多智能体、OpenTelemetry全链路Tracing和Kubernetes生产经验。
